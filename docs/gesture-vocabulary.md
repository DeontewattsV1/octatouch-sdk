# Canonical Gesture Vocabulary

This file is the binding declaration for gesture-to-intent mappings.

- Single tap → Select / Confirm
- Double tap → Select Word
- Triple tap → Select Paragraph / Line
- Long press + drag → Select Custom Block
- Short swipe → Change Track / Page
- Two-finger tap → Save Highlight
- Three-finger pinch-in → Copy Selection
- Three-finger pinch-out → Paste Clipboard
- Three-finger swipe left → Undo
- Three-finger swipe right → Redo
- Three-finger tap → Open Clipboard / Zoom / Screen Curtain
